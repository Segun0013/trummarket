# Visual direction — «Кошелича»

## Confirmed mobile foundation

The Mini App uses a **soft personal-finance ledger** direction: a restrained mint background, a deep teal balance surface, off-white cards, green income semantics and copper expense semantics. The mobile preview was checked after the records and category-management UI was added. Its summary hierarchy, readable amounts and compact transaction rows are working well at a 375 px viewport.

## Rules for next screens

Money values should continue to use tabular, authoritative numerals with hierarchy established through scale and weight. Teal represents balance and security, green represents income and growth, and copper represents expense and outflow. New screens should preserve the calm, reassuring Russian copy style and avoid introducing monetization surfaces in this release.

## Follow-up refinements

The header and repeated wallet/ledger motif can be made more distinctive in a later visual polish pass. This must not compromise the existing five-section navigation, interaction density, or Telegram-first mobile ergonomics.
